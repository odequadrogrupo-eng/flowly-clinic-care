# Upload Manual para GitHub

## Objetivo

Enviar a pasta ClinicFlow-Release para um novo repositorio no GitHub, sem usar comandos git no terminal local.

## Passo a passo

1. Acesse https://github.com/new
2. Defina nome do repositorio (ex.: clinicflow)
3. Marque como Public ou Private
4. Clique em Create repository
5. Na pagina do repositorio vazio, clique em uploading an existing file
6. Abra no explorador a pasta ClinicFlow-Release
7. Selecione todo o conteudo da pasta ClinicFlow-Release e arraste para a area de upload do GitHub
8. Aguarde o processamento dos arquivos
9. No campo de mensagem, informe: release inicial clinicflow
10. Clique em Commit changes

## Validacao

- Confirme se os arquivos docs, src, public e supabase foram enviados.
- Confirme se arquivos proibidos nao foram enviados (.env, node_modules, dist, .git).
